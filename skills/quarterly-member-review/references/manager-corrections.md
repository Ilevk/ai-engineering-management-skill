# 매니저 수정과 메모리

초안의 매니저 확인 질문을 작성하거나 매니저가 직접 수정·인터뷰로 정정할 때 사용한다. 메인은 작성과 수정 반영을 초안 작성 에이전트에, 검증과 재검증을 별도 검증 에이전트에 배정하고 결과만 취합한다. 아래 작성·읽기·비교·반영은 배정된 역할이 수행한다.

## 매니저 확인 질문과 조사 컨텍스트

확인이 필요한 질문을 구체적으로 적고, 바로 아래에 해당 항목과 관련하여 실제 조사한 컨텍스트를 토글로 제공한다. 매니저가 토글을 열어 배경과 근거를 참고한 뒤 답변하도록 안내한다. 링크만 나열하지 않고 원문에서 확인한 내용을 질문과 연결해 설명한다.

토글에는 업무의 발단·목적과 진행 흐름, 해당 팀원의 역할·협업 관계, 확인된 사실, 미확인·충돌 내용과 확인이 필요한 이유, 실제 근거 링크, 답변이 평가 문장이나 개인 귀속에 미치는 영향을 담는다. 날짜와 업무의 계획·진행·완료 상태를 구분해 맥락을 이해할 수 있게 작성한다. 자료가 없는 부분은 미확인으로 남기며 추정으로 채우지 않는다.

Markdown 초안에서는 질문별로 다음 형식의 `<details>` 토글을 사용한다. Notion에 확인 질문을 포함할 때는 같은 내용을 실제 toggle 블록으로 옮긴다.

```markdown
**매니저 확인:** {구체적인 확인 질문}

<details>
<summary>조사 배경과 근거</summary>

- **업무 배경과 흐름:** {발단·목적, 주요 시점과 결정, 현재 확인된 상태}
- **개인의 역할과 협업:** {본인 기여와 협업자의 역할, 귀속이 확인된 범위}
- **확인된 사실:** {질문과 관련하여 원문에서 확인한 내용}
- **미확인 사항과 질문 이유:** {자료 누락·충돌과 매니저의 확인이 필요한 지점}
- **근거:** {실제 조사한 티켓·문서·PR 등의 링크와 각 근거가 뒷받침하는 내용}
- **답변 반영 범위:** {답변에 따라 수정하거나 확정할 평가 문장·개인 역할}

</details>
```

초안 검증 역할은 질문마다 토글이 연결되어 있는지, 질문에 답하는 데 필요한 조사 맥락이 담겼는지, 설명·링크가 원문에 부합하는지 확인한다. 토글 안의 미확인 내용을 평가의 확정 근거로 사용하지 않는다.

## 수정 반영

1. 수정 직전의 초안과 현재 파일을 읽고 달라진 부분을 비교한다.
2. 사실 정정, 서술형 판단 변경과 작성 선호를 구분한다.
3. 매니저가 지적한 사실은 정정 근거 또는 매니저가 확인한 내용이라는 출처를 남겨 해당 회차에 반영한다.
4. 에이전트의 원래 문장, 매니저의 변경과 변경 이유를 해당 회차의 수정 기록으로 남긴다. 이유가 분명하지 않으면 인터뷰로 확인하며 임의로 일반화하지 않는다.
5. 관련 평가 문장과 참고 코멘트를 수정하고 다시 확인한다. 매니저가 제공한 최종 판단은 에이전트의 제안보다 우선한다.

## 장기 메모리 범위

장기 메모리에는 매니저의 작성 선호와 면담 순서만 저장한다. 예를 들어 문장의 길이, 강조 방식이나 선호하는 면담 진행 순서가 실제 수정과 설명에서 확인된 경우에 해당한다.

개인별 사실 정정, 개인에 대한 평가 판단, 원문 자료와 분기별 실적은 해당 회차 기록으로 남긴다. 이 내용을 다음 회차의 사실 근거나 지속적인 개인 특성으로 재사용하지 않는다.

저장 위치는 현재 환경의 로컬 또는 리모트 메모리 중 매니저가 지정한 곳을 따른다. 위치나 사용 범위가 정해지지 않았으면 확인한 뒤 저장한다. 현재 환경의 메모리 쓰기 규칙과 사용자 권한을 따른다.

기록은 매니저를 구분하고 선호 내용, 적용 범위, 변경 이유와 갱신 시점을 포함한다. 일회성 문서 수정을 일반적인 선호로 확정하지 않는다. 다음 회차에 적용할 수 있는지 불명확하면 매니저에게 확인한다.

다음 회차에는 관련 메모리를 읽되 이번 요청을 우선한다. 기억한 선호가 바뀌면 해당 메모리의 갱신 규칙에 따라 새 내용을 반영한다. 작성 선호를 근거의 사실 여부, Job Level 요구사항이나 점수 판단의 대체물로 쓰지 않는다.

저장이 실패하면 저장되었다고 보고하지 않는다. 확인된 선호와 아직 저장되지 않은 내용을 구분해 알리고, 개인별 자료를 다른 위치에 임의로 복사하지 않는다.
