# AI Engineering Management Skills

엔지니어링 매니저의 팀원별 평가서 작성과 평가 면담 준비를 지원하는 유저 레벨 스킬 저장소다.

평가 기준과 데이터 소스는 매니저가 제공한다. 이 저장소는 자료를 확인하고 평가서와 면담 자료로 정리하는 절차를 관리한다. 점수와 등급 판단은 인간 매니저가 맡는다.

| 스킬 | 역할 |
| --- | --- |
| `quarterly-member-review` | 주어진 팀의 팀원별 분기 평가서 작성 |
| `review-meeting-prep` | 작성된 평가서를 바탕으로 면담 준비 |

인터뷰에서 확인한 작성 절차를 반영했다. 팀 단위 평가서는 범위에 포함하지 않는다.

평가서 작성은 착수 확인 → fast-tier 원문 수집과 독립 검증 → top-tier 목표별 그룹핑과 독립 검증 → 별도 top-tier Markdown 초안과 독립 검증 → 매니저 수정 → 지정 포맷의 최종본 순서로 진행한다. 서술형 참고 의견은 제안할 수 있으며 최종 판단은 매니저가 맡는다.

두 스킬 모두 메인 에이전트는 배정과 진행 상태, 인간 확인 및 검증 결과 취합만 맡는다. 면담 준비의 작성·피드백 수정·검증·메모리 기록과 저장도 서브 에이전트가 수행한다. 각 역할의 실제 모델명과 수집 범위를 회차별로 기록하며 부분 수집을 완료로 보고하지 않는다.

면담 준비는 팀원의 현재 수준과 다음 수준의 기대치, 매니저의 지원과 상위 매니저 논의 사항을 다룬다. 별도 면담 순서가 없으면 평가서 전달 → 1주일 이내 면담 → 피드백 반영 → 제출 순서를 사용한다.

## 구성

- `skills/<skill-name>/SKILL.md`: 독립적으로 설치할 스킬의 지침
- `skills/<skill-name>/agents/openai.yaml`: 스킬 표시 정보
- [docs/skill-design.md](docs/skill-design.md): 확정 사항, 남은 질문과 검증 계획

각 스킬 폴더는 독립적으로 유저 레벨 스킬 경로에 설치할 수 있다. 로컬 저장소에서 원본을 관리하고 설치 시 각 스킬 폴더를 복사한다. 원본을 수정하면 설치본도 갱신한다.

장기 메모리에는 매니저의 작성 선호와 면담 순서만 저장한다. 개인별 사실 정정은 해당 평가 회차의 기록으로 관리한다.

개인별 평가 자료와 작성 결과는 이 저장소에 저장하지 않는다. 실제 작업 시에는 매니저가 지정한 위치와 접근 범위를 따른다.


## 검증과 설치 상태

2026-10-05 개정본은 허구 로컬 자료에서 수집 수정·독립 재검증, 별도 역할의 그룹핑·초안·면담 준비와 각 단계 독립 검증을 통과했다. 초기 슬롯 오류로 중단된 기록과 이후 완료된 검증을 구분해 [설계 및 실행 근거](docs/skill-design.md)에 남겼다. 지원 runtime 모델명과 역할을 기록했으며 글로벌 최신 모델 순위는 검증하지 않았다.

실제 커넥터 통합, 인간 매니저의 사실 검토·피드백 반영, private 외부 저장, 전달·초대·제출 및 장기 메모리 쓰기는 미검증이다. 두 스킬을 `~/.codex/skills/` 아래에 각각 물리적 복사로 설치했다. 원본과 설치본의 바이트·SHA-256 일치, quick_validate, YAML과 자체 참조 검사가 통과했다. 실행 근거와 미검증 범위는 위 설계 문서에 기록했다. 커밋·push는 하지 않았다.
